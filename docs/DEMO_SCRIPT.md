# Demo script: ShieldLedger NG (target 5:00, window 4:50–5:10)

**Before recording:**
- Run `make dev` in one terminal.
- Open `http://localhost:5173` at 1440×900 or larger (100% zoom). Payment Run is the default screen and reads top to bottom as three steps: **1 Drop invoices**, **2 The answer**, **3 What needs you**.
- To start from an empty run, call `curl -X POST "localhost:8000/api/dev/reset-demo?ingest_pack=false"` and reload. `make reset-demo` instead resets and loads the pack in about 1–2 s.
- No API key is needed. The status line reads "Gemini: not configured, offline parser active". Say so on camera: the LLM is optional, and Python decides.
