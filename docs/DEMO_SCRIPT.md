# Demo script: ShieldLedger NG (target 5:00, window 4:50–5:10)

**Before recording:**
- Run `make dev` in one terminal.
- Open `http://localhost:5173` at 1400×900 or larger and zoom the browser to 110%. At 1024 px and wider, Payment Run shows the case list and the case file side by side.
- To start from an empty run, call `curl -X POST "localhost:8000/api/dev/reset-demo?ingest_pack=false"` and reload. `make reset-demo` instead resets and loads the pack in about 1–2 s.
- No API key is needed. The header reads "Gemini: not configured, offline parser active" and each case shows an `offline_regex` engine badge. Say so on camera: the LLM is optional, and Python decides.
